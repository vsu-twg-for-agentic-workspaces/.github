# 🏛️ `.github` — VSU TWG for Agentic Workspaces Community Repository

Welcome to the central configuration and community health repository for the **VSU Technical Working Group for Agentic Workspaces** at **Visayas State University**.

## 📌 Repository Purpose

This repository houses:
1. **Organization Profile (`profile/README.md`)**: The public and member landing page displayed on [https://github.com/vsu-twg-for-agentic-workspaces](https://github.com/vsu-twg-for-agentic-workspaces).
2. **Branding Assets (`profile/assets/`)**: High-resolution and vector emblems, avatars, and lockups adhering strictly to the [VSU Brand Book](https://brandbook.vsu.edu.ph).
3. **Community Health Defaults**:
   - [`CONTRIBUTING.md`](CONTRIBUTING.md) — Workflow guidelines, issue-first lifecycle, and multi-facilitator review standards.
   - [`SECURITY.md`](SECURITY.md) — Data privacy and security governance under the Philippine Data Privacy Act (RA 10173).
   - [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — Community values centered on VSU's core RITE principles (Relevance, Integrity, Truth, Excellence).
   - `.github/ISSUE_TEMPLATE/` — Default issue templates applied across organization repositories.
